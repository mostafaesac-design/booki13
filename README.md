# Bookia

Bookia is a responsive bookstore mobile application developed using Flutter and Dart.

The application allows users to browse and search for books, view book details, manage their wishlist and cart, place orders, track previous orders, and manage their profiles.

## Features

* User authentication
* Password recovery
* Arabic and English localization
* Book search and details
* Wishlist management
* Shopping cart
* Checkout and order placement
* Order history and details
* Profile management
* Responsive user interface
* REST API integration

## Technologies

* Flutter and Dart
* Bloc/Cubit
* Dio
* REST API
* Repository Pattern
* Shared Preferences
* Easy Localization
* ScreenUtil
* Cached Network Image

## Architecture

The project follows a feature-first layered architecture with the Repository Pattern and Bloc/Cubit for state management.
